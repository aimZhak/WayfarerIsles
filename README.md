# Wayfarer Isles

Download page for the Wayfarer Isles launcher (a private test with friends).

1. Download `WayfarerIsles-Setup.exe` from the latest release (Releases, on the right).
2. Run it. Windows may say "unknown publisher": click **More info → Run anyway** (the launcher is not code-signed yet).
3. The launcher installs itself, then downloads the game and keeps both up to date.

This repository holds only the installer and the launcher's updates. The game's source code is not here.
